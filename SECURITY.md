# Security and privacy

NEO is local-first. Do not commit a user's `data/`, model files, SQLite databases, logs,
machine profiles, screenshots, `.env`, or generated portable releases.

File discovery, screen capture, public web search, device profiling, malware scans and
system actions must remain separately permission-gated. Discovery is read-only. A system
mutation must show an exact preview and receive a fresh confirmation before execution.

Report vulnerabilities privately to the repository owner. Do not include real personal
files, access tokens, account data, screenshots, or machine identifiers in a report.
